## Overview

SuperPrice is a grocery price comparison platform for Australian
supermarkets. Users search for a product, see prices side by side
from Coles, Woolworths, and Aldi.

## How it works

The frontend is React with TypeScript, talking to a Spring Boot
backend over REST.

## What I learned

The team-coding parts were harder than the code itself.
