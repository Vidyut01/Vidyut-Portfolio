# Vidyut Portfolio

A high-performance software engineering portfolio built using a zero client-side JavaScript approach.

**Live Website**: <https://vidyutvenkatesan.com>

## Tech Stack

This site is built using the **Astro** framework, using static site generation to create the HTML/CSS files at build time. To avoid package bloat and keep performance optimal, the codebase relies on exactly one dependency (`astro`).

All content is written in Markdown, stored in the `src/content` directory, and managed via Astro's type-safe content collections. The site is automatically deployed and hosted on **Cloudflare Pages**.
